# ES-白奕
AI直接探究词义，人工介入筛选的20万词形码词库。面向通用用途，原生支持奕码方案。

## 词库属性
本词库定位通用，融入了少量垂直领域词汇，以拓展适用场景。

## 文件结构
```
|-- ES_白奕
    |-- README.md
    |-- 白奕词表.txt # ⭐词库文件
    |-- Rime_ES_白奕 # Rime - 白奕方案
    |-- 人工删改记录表 # 对词表删改的记录
```

## 制作思路
- **形码优先**  
	- 拼音方案对数字词（如“二十八”）容忍度高，但四码定长的形码编码空间有限，只有四个码用来打词，数字词易占用其他词码，需筛除。  
	- 拼音需处理多音字与同音词，形码则无此困扰，可更专注于整体词频优化。
	- 后续计划：重新添回数词并考虑多音字，制作拼音可用的分支。
- **AI究义**
	- 分词过程中使用模型直接探究词义以判定词语可用性，尽最大可能规避伪词。
	- 纯ai判定当然不可信。同时使用凝固度+自由度算法，N-Gram模型等多方核验。
	- 必须进行人工抽查。
- **持续更新**
	- 词库制作非一朝一夕。每天定量人工排查以优化词库。

## 名称由来
词库最初版来自[白霜词库](https://github.com/gaboolic/rime-frost)，但很快我意识到一个为拼音优化的词库难以直接挪用到形码，故自己从头做起。

为纪念初版，将本词库命名为白奕词库。
